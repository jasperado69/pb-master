# Boris Bowl Watch

A small offline-friendly PWA for a 3-day friend-group joke wager. Boris can unlock the admin screen, log date/time/location for each confirmed movement, and friends can add bets from the bet board.

## Features

- 3-day challenge countdown
- Boris admin logging with date, time, confidence, notes, and optional browser geolocation
- Embedded OpenStreetMap preview for saved locations
- Friend betting board with names, predictions, and stakes
- Local-first storage with `localStorage`

> Privacy note: only track or share someone’s location with their consent.
